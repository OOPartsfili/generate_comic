## 2.1.1 · Spark 出图路由修复与脱敏诊断

- 故障复现：文字模型选择 `gpt-5.3-codex-spark` 时，旧版把同一模型用于插画。隔离请求只返回了文字和可复制的绘图提示，没有 `imageGeneration` 结果。模型目录明确列出 Spark 的 `inputModalities: ["text"]`，默认 `gpt-5.5` 为 `["text", "image"]`。
- 修复验证：保留文字设置为 Spark，插画请求独立路由至 `gpt-5.5`。同一本机官方 Codex 0.138.0、同一 ChatGPT Pro 登录成功生成橘猫与蓝色茶杯水彩 PNG，已人工查看。约 38 秒完成，日志包含 `imageGeneration: completed`、`image_saved` 和完整诊断编号链路。测试没有改写用户作品或调用 API Key 通道。
- 新日志位于本地 `workspace/logs`，白名单字段、约 2 MB 轮转、错误关联编号、只记录 stderr 分类。日志读写失败不会丢弃生成结果。旧版没有记录的事件不能追溯补写。
- 回归覆盖：Spark 文字与图片分离、最终 turn items 收图、无工具调用/工具失败区分、无图像模型时不发请求、不可用时停止后续画格、诊断落盘、日志脱敏/轮转/写入异常、导出鉴权且不触发模型。19 组单元/集成测试通过。
