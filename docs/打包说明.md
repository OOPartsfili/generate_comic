# 打包与源码验证

本机 `package.json` 指向已经下载并校验的 Electron 运行目录：`node_modules/electron/dist`。

首次在另一台开发机器重建时：

```powershell
npm install
npx install-electron --no
npm run package
```

若 Node.js 下载 Electron 失败但系统网络可用，可用系统代理下载官方发行档案，并对照 `node_modules/electron/checksums.json` 校验 SHA256，校验通过后再解压。不要跳过校验，也不需要为运行程序安装开发依赖。

打包后，单文件程序输出至 `release/墨格创作室-2.1.1.exe`，可复制到任意目录双击运行。Git 仓库不保存 EXE、构建缓存或本机快捷方式。

Codex 运行时与账号凭据不打包进墨格。目标电脑须安装官方 Codex CLI；通过 PATH 自动发现，也可配置 `MOGE_CODEX_PATH` 或界面中的程序路径。墨格通过隐藏的 stdio 子进程启动 Codex，登录与刷新由官方处理。当前接入已在 Codex CLI 0.138.0 验证，模型从该版本返回的可用列表选择。

本机已提供项目根目录的「墨格创作室.exe」。日常也可以双击「墨格创作室（快速启动）」，该快捷方式直接打开 `release/win-unpacked` 中已经展开的程序，省去单文件程序每次启动时的解压过程。请保留整个 win-unpacked 文件夹。

程序没有自动发布、上传作品、远程更新或自动购买额度功能。所有生成由界面中的明确操作触发。
